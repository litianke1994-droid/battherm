# 设计说明（中文笔记）

## 1. 研究问题

给定 BMS 已测量的过去 120 s 信号（电流、电压、表面温度、环境温度）和未来 60 s 的计划电流，
预测未来 60 s 每一秒的电芯表面温升。

- **为什么预测温升而不是绝对温度**：不同环境温度（−20 ~ 40 °C）下绝对温度分布完全不同，
  温升的分布更一致，模型更容易跨温度泛化；而误差数值完全相同。
- **为什么给未来电流**：温升主要由未来的焦耳热决定。真实场景里对应“计划负载”（导航坡度、
  快充计划）。这是一个假设，需要在论文/报告里明确写出；如果只用历史，任务退化为外推，
  persistence 会非常难被超越。
- **不应推断的内容**：电芯内部（core）温度、热失控、老化后的热行为——数据里都没有。

## 2. 物理模型（基线 + 混合模型的骨架）

集总热容模型：

    C_th · dT/dt = I² · R(T) − hA · (T − T_amb)

令 R(T)/C_th ≈ a0 + a1·d + a2·d²（d = T − 25 °C），k = hA/C_th，参数全部线性。
用积分形式 `T[t+m] − T[t] = Σ φ·dt` 做最小二乘，而不是对温度做差分求 dT/dt
（差分会把传感器噪声放大 1/dt 倍）。

可解释的输出：热时间常数 τ = 1/k（秒）。HG2 上拟合得到 τ ≈ 490–530 s（单节 18650、
温箱自然对流）。数量级合理；与具体文献数值的对比仍待你自己查证。

**v2：Arrhenius 形式。** 二次多项式 R(T) 在训练温区（−20…25 °C）内拟合得很好，但它不单调：
外推到 40 °C 时又向上弯，预测的焦耳热是 25 °C 时的 2 倍，方向完全错了。v2 改成
R(T)/C_th = a·exp(−β·(T−25))，β ≥ 0 用网格搜索。这样无论外推到哪里，“越热电阻越小”都成立。
HG2 上 β ≈ 0.048 1/K。教训：**物理先验的“形状”比训练集上的拟合误差更重要。**

## 3. 数据切分 —— 本项目最重要的一条规则

同一条测量曲线里相邻窗口高度重叠（stride 5 s、窗口 120 s）。如果随机切窗口，测试集几乎就是
训练集的复制，指标会虚高。所以：

- 切分单位是 **整条 cycle**（`cycle_id`），见 `split_cycles`；
- 两个 HG2 协议：未见过的工况（US06、Mixed8）、未见过的环境温度（40 °C 外推）；
- scaler、物理参数、ridge 的 alpha 只用 train/val；test 只在最后用一次；
- `tests/test_data.py` 里有对应的检查（窗口不跨 cycle、split 不重叠、scaler 只用训练统计量）。

## 4. 深度学习部分的设计取舍

| 选择 | 原因 |
|---|---|
| encoder–decoder | 过去窗口 → 热状态；decoder 像积分 ODE 一样逐步消费未来电流 |
| 输出增量再 cumsum | 预测是一条轨迹，而不是 60 个互相独立的数 |
| 沿预测步因果 | 第 h 步只能看到 ≤ h 的未来电流（测试 `test_net_shapes_and_causality`） |
| hybrid = 物理 + LSTM 残差 | 网络只学物理模型没覆盖的部分（极化热、低温电阻非线性、传感器滞后），外推温度时更稳 |
| 目标用一个标量标准化 | 损失与 K² 成比例，不会过度放大 1 s 预测步的噪声 |

## 5. 结果要怎么读

1. 先看 `persistence`：任何模型都必须明显更好，否则说明任务设定/数据有问题。
2. `physics` vs `ridge`：线性模型能否已经足够？
3. `lstm`/`cnn` vs `hybrid_lstm`：在 **环境温度外推** 协议下，hybrid 是否更稳——这是项目的核心结论候选。
4. 按环境温度分组的误差：低温下内阻大、温升大，误差通常更大，要在报告里解释。
5. 失败案例：找误差最大的窗口，看对应的电流/温度曲线，判断是模型问题还是数据问题（例如热电偶接触、日志中断）。

## 8. 实验得到的结论（详见 results_hg2.md）

1. **未见工况（US06 + Mixed8）**：hybrid_lstm 最好，RMSE 0.089 K，持久性基线为 0.168 K；
   它也最稳定（3 个 seed 几乎相同，最坏误差最小）。
2. **未见环境温度（40 °C）**：
   - v1 预注册的结果是**所有模型都输给了持久性基线**，hybrid 最差。原因有两个：物理先验
     外推方向错误；网络看到了训练中从没出现过的绝对温度。
   - v2 换成 Arrhenius 形式 + 相对温度输入，选择依据是 25 °C 的“伪外推”开发集，测试集只
     跑一次。hybrid 降到 0.072 K，持久性基线为 0.083 K。
   - 注意：v2 是在看过 v1 测试结果后才去找的修正，因此属于“部分事后”的结果。写简历或面试
     时要如实说明，这本身也是一个很好的讨论点。
3. **传感器分辨率 0.105 K**：误差再小也有约 0.04 K 的底噪。不要把 0.002 K 的差别当成
   “模型更好”。

面试可以讲的一句话：*“物理先验让网络更准、更稳；但错误的先验在外推时比没有先验更糟，
所以先验要约束在正确的物理形状上，再用模拟外推的验证集来检验。”*
